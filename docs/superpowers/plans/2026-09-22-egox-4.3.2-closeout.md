# EgoX 4.3.2 Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an evidence-backed EgoX 4.3.2 Android 16/arm64-v8a closeout that removes active Asteria branding, fixes the confirmed shortcut package bug, and makes no feature changes.

**Architecture:** Keep the external application identity (`com.egox`), signing identity, persisted data, serialization, plugin contracts, and legacy internal namespaces stable. Add a deterministic Gradle branding contract, make the smallest runtime/build/documentation edits needed to satisfy it, then use the existing unit, lint, libcore, and APK gates to discover and fix only reproducible defects.

**Tech Stack:** Android Gradle Plugin 8.10.0, Gradle 8.11.1, Kotlin/Java, Android API 36, JUnit 4, Android Lint, aapt, apksigner, PowerShell 7.

**Spec:** `docs/superpowers/specs/2026-09-22-egox-4.3.2-closeout-design.md`

## Global Constraints

- Preserve application ID `com.egox`, the EgoX 4.3.1 signing certificate, application data, databases, Room schemas, preference keys, backup schema, Parcelable/Kryo layout, and Router stable identifiers.
- Preserve the internal namespaces `io.nekohasekai.sagernet` and `moe.matsuri.nb4a`.
- Preserve protocol, Router, subscription, URL Test, backup/restore, Requests, VPN, notification, and plugin behavior unless a reproducible defect requires a minimal fix.
- Keep `minSdk=36`, `targetSdk=36`, `compileSdk=36`, and only the `arm64-v8a` application/native ABI.
- Set `VERSION_NAME=4.3.2`, `PRE_VERSION_NAME=pre-4.3.2`, raw `VERSION_CODE=61`, and packaged Android `versionCode=305`.
- Keep required NekoBox/SagerNet/Matsuri upstream attribution and compatibility identifiers; do not treat them as EgoX branding defects.
- Do not add features, redesign UI or runtime behavior, add dependencies, push, publish a release, or expose signing credentials.
- Use one logical commit per task. Do not reset, clean, rewrite history, or discard pre-existing files.

## Review Focus

- An installed 4.3.1 build must accept the 4.3.2 APK as an in-place update: same package, monotonically higher versionCode, and identical signer certificate.
- All four static shortcuts must resolve to `com.egox` while retaining their existing component class names and actions.
- Locale-specific `app_name`, `app_name_long`, and Chinese `tile_title` overrides must not reintroduce Asteria in the packaged resources.
- Removing Asteria build fallbacks must not remove the only usable signing path or change backup import compatibility.
- Native and packaged artifacts must contain `arm64-v8a` only; host-tool `linux-x86_64` text must not be mistaken for an Android x86 ABI.

- [ ] **Step 2: Add the runtime branding contract**

Append this task to `app/build.gradle.kts` before the existing `preBuild` configuration, then add `dependsOn(verifyEgoXBranding)` inside `tasks.named("preBuild")`:

```kotlin
val verifyEgoXBranding by tasks.registering {
    group = "verification"
    description = "Checks the active EgoX runtime branding contract"

    val shortcuts = file("src/main/res/xml/shortcuts.xml")
    val localeStrings = fileTree("src/main/res") {
        include("values*/strings.xml")
    }
    val runtimeSources = files(
        "src/main/java/io/nekohasekai/sagernet/utils/CrashHandler.kt",
        "src/main/java/io/nekohasekai/sagernet/ui/LogcatFragment.kt",
        "src/main/java/io/nekohasekai/sagernet/ui/BackupFragment.kt"
    )

    inputs.files(shortcuts, localeStrings, runtimeSources)

    doLast {
        val problems = mutableListOf<String>()
        val shortcutTargets = Regex("""android:targetPackage="([^"]+)"""")
            .findAll(shortcuts.readText())
            .map { it.groupValues[1] }
            .toList()
        if (shortcutTargets.size != 4 || shortcutTargets.any { it != "com.egox" }) {
            problems += "All four static shortcuts must target com.egox: $shortcutTargets"
        }

        localeStrings.files.sortedBy { it.path }.forEach { stringsFile ->
            if (Regex(""">\\s*Asteria(?: for Android| для Android)?\\s*<""")
                    .containsMatchIn(stringsFile.readText())) {
                problems += "Active Asteria locale branding: ${stringsFile.relativeTo(projectDir)}"
            }
        }

        runtimeSources.files.forEach { sourceFile ->
            if (sourceFile.readText().contains("Asteria")) {
                problems += "Active Asteria runtime branding: ${sourceFile.relativeTo(projectDir)}"
            }
        }

        listOf(
            file("src/main/res/drawable/ic_asteria_foreground.xml"),
            file("src/main/res/drawable/ic_asteria_monochrome.xml")
        ).filter(File::exists).forEach {
            problems += "Unreferenced Asteria resource remains: ${it.relativeTo(projectDir)}"
        }

        if (problems.isNotEmpty()) {
            throw GradleException(problems.joinToString(separator = "\\n"))
        }
    }
}
```

Add `import java.io.File` to the imports in `app/build.gradle.kts`.
